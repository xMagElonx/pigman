# 音色放这里

把两条音色按**下面的文件名**放进这个目录，砍一刀就会响。**不用改任何代码。**

| 文件名 | 什么时候响 | 要什么音色 |
|---|---|---|
| `sfx_swing_whoosh.ogg` | 每次挥击（挥出去那一刻） | 短、亮、**不要低频** —— 一层「风」 |
| `sfx_swing_hit.ogg` | 命中时**叠在上面** | 骤停、暗、**要有低频冲击** —— 一层「撞」 |
| `sfx_limb_sever.ogg` | 断肢（**M4 才用，现在别做**） | 只占个名字 |

扩展名支持 `.ogg` / `.wav` / `.mp3`（先塞 wav 试听也行，不用先转格式）。

## 为什么是这两条、以及为什么必须这样分

M2 的验收是**「闭眼分辨切中 / 挥空」**。做法不是「两种完全不同的音」，而是：

- **挥空** = 只有 whoosh → 一层（风）
- **命中** = whoosh + hit 叠在一起 → 两层（风 + 撞）

判据是**「有没有第二层」**。所以：
> ⚠️ **whoosh 每次必须完全一样**（不许随机音高、不许随机变体）。
> 底层一旦抖动，第二层就会被掩掉，这条验收就永远过不了。

（代码里 `pitch_scale` 已写死 1.0，你不用担心手滑。）

## 现在没放文件会怎样

**不会报错、不会崩** —— 静默跳过。所以「先接线、后录音」是安全的。
在调参面板（Tab）最下面拖动「音效音量 dB」可以调总音量。
