## 一、项目背景与目标

| 项 | 内容 |
|---|---|
| 名称 | 《猪人 PIGMAN》 |
| 定位 | 低模（low-poly）第一人称**超现实恐怖动作**游戏 |
| 团队 | **单人 + AI 辅助**。用户（导演）**不懂编程**（接触过 UDK/UE4，未跑过完整开发流程），**有音乐制作能力**，法学背景 |
| 引擎 | **Godot 4.7.2 stable**（GDScript + .tscn，纯文本；选它的决定性理由＝AI 改不动 UE 蓝图，只能改文本） |
| 权威设计文档 | 用户自产 `猪人_游戏项目计划书_v0.2.docx` |
| 开发模式 | M0–M7 里程碑，**不设日历工期**；一手「先好玩再复杂」 |

**核心 USP（三条）**：
1. **肉体构筑** —— 玩家装备的是**身体**（手臂/腿），不是武器。
2. **非固定连招** —— 战斗读的是状态/惯性/距离，不是背连招。
3. **肢体残留意识** —— 被移植的肢体保留原主的行为/记忆痕迹。

**三条不可妥协**：① 先好玩再复杂 ② 一致的规则胜过无限自由 ③ 玩家可以无视引导。

**美学方向**：异化 / 拥挤 / 城市焦虑 / 肉体恐怖 / 荒诞 / 黑色幽默 / 培根式扭曲。**明确排斥**丧尸、血浆爽片。

**世界观**：猪化＝把人的隐藏本能肉体化。开场＝**广州地铁早高峰**。章节：地铁（教学）→ 地下商业 → 办公区 → 城市地下系统 → 未知。

## 二、当前进展与范围

### 2.1 里程碑位置
- **M0（环境）+ M1（移动）+ M2（挥砍 + 靶子）已完成并迭代多轮。**
- **当前处于 M2 → M3 之间**（M3＝一种会反应的敌人）。
- 按六阶段流程（立项 → 预制作 → 制作 → 打磨 → 发行 → 发售后），M0–M7 全部属于**第 2 阶段「预制作」**；整条流程约走完 **8%**。
- ⚠️ **M2 的验收标准「闭眼分辨切中/挥空」至今未通过**，根源在**声音**（音效钩子是空的）。

### 2.3 已实现的可玩内容
- 灰盒房间 + 第一人称移动（走/跑/跳/转向惯性/空中控制）。
- **屠刀**：14 顶点轮廓挤出、单侧开刃、楔形截面、三段配色分面；刀柄四件（Neck/Handle/Butt）参数化；无护手。
- **挥砍**：windup 0.12s / active 0.10s / recovery 0.30s；斜劈（`swing_tilt 30°`）；命中＝胶囊 + ShapeCast3D 扫掠；顿帧 0.06s + 屏震。
- **靶子**：可被击打、HP 递减、可倒下复位。
- **一键调参**：34 根滑条 + 自动保存到 `user://tuning.cfg`（**手感值不进 Git**）。

### 2.4 明确的「不做」（当前范围外）
剧情 / 菜单 / 存档系统 / 成就 / Steam 接入 / 第二个敌人 / 任何正式美术（全灰盒）/ Roguelite 机制（随机、构筑、死亡重来）/ 断肢（M4）/ 敌人 AI（M3）/ 手模型（用户说「之后」）。

### 2.5 关键技术定案（v0.2）
- **预设切断点**，放弃任意网格切割（成本不可控）。
- 玩家＝**脚本控制的 CharacterBody3D**（物理只服务于断肢/倒地，不接管玩家身体）。
- **镜子兼复活点**。

## 三、已知风险与历史教训（供评审锐化）

1. **定位漂移**：用户口头自称「砍杀爽游」，但权威文档是「超现实恐怖动作」，且 USP 把异化身体定性为**代价**。「爽」与「不受控」对同一批参数给出相反答案。
2. **需求 > 验收**：加需求的速度 > 验收的速度（飞踢、四向未做又来新需求）。
3. **作者性依赖单点**：手感/声音/设定只有用户能判断；AI 只能做管道。M2 验收卡在声音上，因为音效钩子刻意留空。
4. **范围失控风险**：美术是「未来外包」；AI 建模能力边界＝「能被参数描述的几何」擅长、「有机造型」不擅长。
5. **无远程仓库**：Git 仅在本地（无备份、无协作冗余）。
6. **质量闭环薄弱**：headless 自检能验数值关系，但**打击感/视觉/听觉必须真人开窗口**，而这一步长期滞后。
