# 《猪人》权利清单（Rights Ledger）

> 规则只有一条：**每引入一个外部资源，当场记一行。** 不回溯、不整理、不美化。
> 每天成本约一行。它是这个项目里唯一一份"顺手就能攒出来"的可出示物。

---

## 空白台账

| 日期 | 引入的东西 | 来源 / 作者 | 授权方式 | 能商用吗 | 凭证在哪 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |
|  |  |  |  |  |  |

「能商用吗」只填三种：**能 / 不能 / 不确定**。填「不确定」不是失败，是标记——它就是你后面要查的那一条。

## 必须覆盖的范围（照这个清单收，别漏）

**素材类**
- 字体（最容易踩，商业字体授权极贵）
- 音效、音乐（含你自己做的——你的权利也要写进来）
- 贴图、模型、参考图
- **AI 生成的素材**（见下）

**人力类**
- 未来外包的美术 → 合同里**委托作品的著作权归属**必须写明
- 任何署名要求

**工具类**
- 引擎（Godot 是 MIT）、插件、第三方库的商用条款

**标识类**
- 游戏名称「猪人 / PIGMAN」——上架前先查商标

## 你在这个项目里会真实撞上的四条（2026-10 核实）

**1. AI 生成的素材归谁？**
全国首例「AI 文生图」案（北京互联网法院 2023 年 11 月判，2025 年被美国版权局官方报告援引）确立的标准是：**看自然人的独创性智力投入**。
- 反复打磨提示词、调试参数、多轮筛选 → 构成美术作品，著作权归使用者
- 只敲一句简单提示词、构图色彩全交给 AI → 甘肃高院 2025 年度典型案例认定**不构成作品**

→ 你的每一个 AI 占位素材，都落在这条线的某一边。**记来源和提示词，就是在给自己留证据。**

**2. AI 合成声音。**
2024 年 4 月，全国首例「AI 声音侵权案」宣判，自然人声音权益延伸至 AI 合成声音。你是做音乐的——这条直接撞你。

**3. 风格 vs 画面。**
著作权保护**表达**，不保护**风格**。你的美学方向写了 Francis Bacon——「培根式的扭曲」作为方向没问题；但直接使用或改编他的具体画面是另一回事（他 1992 年去世，在中国的保护期到 2042 年）。

**4. 训练数据与风格盗用。**
2025 年 6 月，迪士尼、环球等联合起诉 Midjourney，指控未经授权使用原创素材训练模型、模仿知名 IP 风格牟利。这条现在还没有定论——是灰区，也是你可以在这儿做功课的地方。

## 为什么值得做

这份台账有两种用法，都不需要你为它额外花时间：

- **对这个项目**：上架前你会需要它，那时回溯成本极高。
- **对你自己**：它是你已经在做的「权利链」在一条全新赛道上的实操样本。区别在于——**别的例子是看来的，这一份是你亲手签过的。**
