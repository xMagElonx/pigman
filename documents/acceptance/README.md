# 验收台账 · 怎么用

## 这东西是干嘛的
机器验得动的，已经有「自检门」替你盯着（数值 / 结构 / 存档，双击 `check.cmd` 全绿就行）。
但有**三类东西机器验不了，只有你能验**：

- **打击感** —— 砍上去有没有感觉
- **视觉** —— 长得对不对
- **听觉** —— 声音对不对

这三类过去**一点痕迹都没留** —— 做了没人知道，没做也没人知道。
`log.md` 就是补这个洞：**一行 = 一次验收**。

## 你要做的只有一件事
**对不上 → 整屏截图 → 在 `log.md` 加一行。**
- 截图存到本目录（`documents/acceptance/`）
- 录屏大文件丢到本地 `clips/`，台账里只写文件名
- 打勾的账写进 `log.md` 一行

你本来就在「截图发我」，只是以前没地方存。现在有地方存了 —— 成本 = 一次截图 + 一行字。

## 什么时候记
- **每次改动后**（我改完代码 / 模型 → 你开窗口看一眼 → 记一行）
- **每次你开窗口玩过之后**（顺手一行）

## 怎么判 —— 验收卡上已经写好了，直接照抄
别自己想标准，每张卡每条都给了「怎么判」：

- **柄卡**（`knife-handle-check.svg`）：**缺 H1 或 H4 → 说一声；只缺 H5 → 我调材质**
- **刀身卡**（`knife-visual-check.svg`）：五条都在 → 通过；只缺 F5 → 说一声；缺 F2 或 F3 → 形状没生效，说一声
- **声音**：闭眼砍一刀，**数层数** —— 挥空一层（风）；命中两层（风 + 撞）

## 结果怎么填（只五档）
`PASS` / `部分` / `FAIL` / `BLOCKED` / `待做`

- `BLOCKED` 只用在一种情况：**东西还没做出来，验不了**（例：音色还没录）
- `待做` ＝ **你还没验过**（＝未做）
