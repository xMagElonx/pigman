---

## 为什么要在测试前填

调参最大的敌人不是调不出来，是**你不知道自己在验证什么**。
你滑到 4.5，觉得「还行」——可你没有参照系：你没做过游戏，你不知道 4.0 m/s 是慢是快。

先写下一个数，你就有了一份**离场承诺**。你不再是漫无目的地拖滑条，而是在验证一个具体假设。

它还有一个副产品，比调出好手感更值钱：**它会告诉你，你的直觉有多准。**

## A. 六个数字 —— 我以为应该是多少

先不看上面的代码初值。写下你的**直觉值**，并给一个理由。
理由比数字重要：测完你才知道是「数字错了」还是「我以为它是什么」错了。

| # | 参数 | 我猜应该是 | 我凭什么这么猜 |
|---|---|---|---|
| 1 | walk_speed 穿行速度 | ______ m/s | |
| 2 | sprint_speed 冲刺速度 | ______ m/s | |
| 3 | acceleration 加速度 | ______ | |
| 4 | deceleration 减速度 | ______ | |
| 5 | mouse_sensitivity 灵敏度 | ______ | |
| 6 | eye_height 眼睛高度 | ______ m | |

**第 1 题的正确锚点不是游戏，是你自己：**
你的第一章是**广州地铁早高峰**。在那种车厢里，一个人**实际能走多快**？
用你的身体去回忆——你挤过那种车厢。这一题不是让你猜游戏数值，是让你把那具身体的体验翻译成数字。

## B. 三个只靠感觉的判断（各一句话）

1. **起步**：从站着到全速，你希望它像**一个人**（有重量，慢慢起来）还是像**一台机器**（推杆即满速）？
   大概几秒？______

2. **松手**：停下时你希望自己**滑出去一段**（惯性），还是**立刻钉住**？
   这决定 `deceleration` 要小于还是大于 `acceleration`。______

3. **冲刺**：全速冲的时候，你还想能转向吗？还是希望它**很难拐**、会滑出去？
   如果选后者，那是《猪人》的一个卖点，不是缺点。______
